# Irreverents MA-02 / MA-03–05 — Native asset production pack

This is a candidate production pack, with actual alpha RGBA PNG sprites at native 16px-multiple sizes (not a concept sheet masquerading as a runtime atlas).

* MA-02: two bitmap ASCII 32–126 (95 glyph) font atlas PNGs (light and dark), each 160×84, 10×14 glyph cells. Includes char map and metrics in manifest. No font files distributed.
* MA-03: two bandit-camp tents (closed and open), banner, torch, and flag.
* MA-04: five palisade prefab sections (left/middle segments/right). These are 64×48 source-derived prefabs, **not** promised as seamless auto-tile cells.
* MA-05: two fully equipped weapon racks plus arrow barrel and crate/sack supply.

All sprites are separated with native RGBA and hard transparency, dimensions verified. 320×180 screenshot uses actual extracted assets at 1x and 4x nearest-neighbor magnification. The complete large source art is preserved in source/.

IMPORTANT: Owner and Claude should evaluate stylistic fit and final actual iPhone browser legibility. No GitHub deployment or tested physics is claimed. These are candidates for immediate implementation, not proof that the game already integrated them.
