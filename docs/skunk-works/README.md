## Domains already researched

One entry per run: the report file, its theme, how many domains, which
were far field, and the list. Later runs read every research log before
choosing domains, so they go somewhere new. Also note any environment
limit a run hit (web proxy blocks, a search-budget ceiling past some
number of scouts), so the next run can plan around it.

## Evolutions

`evolutions.md` holds the owner's reactions to ideas, verbatim, plus the
threads each opens and anything grown from them. Read it before the
reports: it shows what actually landed. Review progress is tracked in its
table.
