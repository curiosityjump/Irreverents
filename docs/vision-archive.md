# Vision archive

**Archive.** History — read for context, never act on it. Full record of a
vision section once it stops describing what is in progress or still to
come and only describes what already shipped. See `docs/vision.md`'s own
"Reading this document" for the rule, and `docs/vision-partner-role.md`,
"The vision documents", for who writes here (the owner and Vision
Partner) and how.

`docs/vision.md` keeps a short, condensed summary of an archived section
plus a link back here; this file keeps the fuller history (the
stream-of-consciousness quotes, the reasoning, how the thinking evolved)
so a session or the owner can see how a direction got to where it is
without carrying that weight in the document read at the start of every
vision conversation.

Nothing here is current. If something below reads as still open or in
progress, that is this file lagging reality, not reality lagging this
file: check `docs/vision.md` or `docs/plan.md` for the live answer, and
fix whichever doc is wrong.

## Entry format

```markdown
## <the section's own heading in docs/vision.md> — archived <date>

<the section's full text, verbatim, quotes and all>
```

Newest at the bottom. One entry per archived section; never edit an
entry's text after it lands, except to fix a broken link.
